# ChainLumin

ChainLumin enables real-time data synchronization across distributed systems through auto-scaling, high-performance engine architecture.

With ChainLumin, you get a lightweight tool that stays out of your way.

**What you get**

- ChainLumin enables real-time data synchronization
- across distributed systems through auto-scaling,
- high-performance engine architecture

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/ChainLumin.git`
2. `cd ChainLumin`
3. Install in editable mode: `pip install -e .`

## Configuration

ChainLumin is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
